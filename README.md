## Proyectos

### 🏗️ [Automatización EdiLoja](https://github.com/utpl/Atomatizacion_Ediloja)

Plataforma completa para la producción de guías didácticas y metacursos de Canvas.
Todo el sistema orbita alrededor de un documento único: un agente de IA genera el
borrador, los docentes lo revisan en un editor web, un validador aplica las reglas
institucionales y el resultado se publica en Canvas vía API.

Monorepo con API, migrador, pipeline de render y librerías compartidas. Incluye
suite de pruebas, esquemas JSON versionados y documentación propia: arquitectura,
ADRs, contrato front-back y registro de deuda técnica.

`Python 3.13` `FastAPI` `PostgreSQL 17` `Redis + RQ` `SQLAlchemy 2` `Alembic` `JWT + Argon2` `htmx` `Jinja2`

### 🛍️ [Loja Moda](https://github.com/utpl/Loja-Moda) · [ver en vivo](https://loja-moda-delta.vercel.app)

Ecommerce de moda que permite al usuario visualizar cómo le quedaría una prenda a
partir de su propia fotografía. Catálogo, cuentas de usuario y flujo de compra.

`Next.js` `TypeScript` `React` `Vercel`

### 👥 [Apolo](https://github.com/utpl/Apolo) · [ver en vivo](https://apolo-ten.vercel.app)

Aplicación web para el registro y seguimiento de personal, con autenticación y
persistencia sobre Firebase.

`Next.js` `TypeScript` `Firebase` `Vercel`

### 📄 [Pipeline de guías didácticas](https://github.com/utpl/App_Creacion-guias-)

Procesamiento automatizado de documentos Word: normalización de formato APA para
tablas y figuras, detección de tablas fusionadas y conversión a datos
estructurados. Idempotente por diseño — reprocesar un documento nunca altera lo
que ya estaba correcto.

`Python` `python-docx` `Docker` `Alembic`

### 🎓 [Recursos educativos interactivos](https://github.com/utpl/Recursos-Educativos)

Recursos de aprendizaje autocontenidos embebidos en Canvas y Moodle: líneas de
tiempo, emparejamiento drag & drop, gráficos en SVG, quizzes e infografías. Cada
uno es un único archivo HTML sin dependencias externas, construido bajo las
restricciones de Canvas, que elimina JavaScript, manejadores en línea y SVG.

`HTML` `CSS` `JavaScript` `SVG` `Accesibilidad`
